What is Marksmith?

Marksmith is a native macOS markdown editor. Open a file and edit it. Open a folder and see your markdown files in a clean tree view. Toggle between Edit and Preview with a single click. That's it.

No vaults. No subscriptions. No proprietary formats. Your files stay exactly where they are. Marksmith just helps you edit them.

What's new in 1.2 New

  • Formatting toolbar. 15 buttons in the editor's title bar for bold, italic, strikethrough, inline code, headings (H1–H3), bullet / numbered / task lists, links, images, tables, horizontal rules, and block quotes. Click a button or use the matching keyboard shortcut.
  • Toggle behavior. Click a formatting button on already-formatted text and the markers come off. Heading levels swap cleanly (H1 → H2 → H3) without stacking.
  • Auto-numbering. Apply the numbered-list button across multiple lines and they auto-number 1, 2, 3, …
  • Preview safe. The toolbar disables itself when you're in Preview mode so you can't accidentally format read-only content.

Features

Full GitHub Flavored Markdown: headings, bold, italic, tables, task lists, fenced code blocks, block quotes, strikethrough, images, and links. Syntax-highlighted editing with a live preview. Folder mode with a sidebar tree view. In-document Find (⌘F) with match count, replace, and case-sensitive / whole-word options. Standard macOS keyboard shortcuts. Full Dark Mode support.

System requirements

macOS 13 (Ventura) or later. Apple Silicon or Intel Mac.

Privacy

Marksmith has no network access. It does not collect, store, or transmit any data. Your files stay on your Mac.
