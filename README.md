# ⚠️ DO NOT DELETE — Production Support Page

This repo serves **https://zapatify.github.io/marksmith-support/** via GitHub Pages.

That URL is registered as the **Support URL** on Marksmith's Mac App Store listing
([apps.apple.com/.../marksmith/id6762143551](https://apps.apple.com/us/app/marksmith/id6762143551?mt=12)).

If this repo is deleted, GitHub Pages stops serving the URL. The live app's Support
link 404s. The next App Store review will fail. Apple-side metadata changes are slow
to take effect, so the only recovery is restoring this repo within GitHub's 90-day
deleted-repo recovery window.

**Already happened once** (2026-06-16, during a cleanup; recovered by chance while
v1.2.0 was in review). Read the workspace rule at
`~/Repos/.claude/rules/critical-repos.md` before touching this repo.

---

## What's actually here

A single static `index.html` plus this README. The page is intentionally minimal:
app description, contact email, privacy statement, link to the GitHub issue tracker
on `zapatify/marksmith`.

To update the live page, edit `index.html` and push. GitHub Pages auto-rebuilds in
1–2 minutes.
